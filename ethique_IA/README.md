# Usage de l’intelligence artificielle

Le document [Test et charte IA](Test_et_charte_IA_Halophytes.docx) rassemble le test bibliographique et la charte personnelle du projet.

Il doit être consulté pour les modalités de vérification des références, la protection des informations et la déclaration de l’assistance de l’IA.

L’organisation de ce dépôt, l’adaptation du README et le retrait des chemins locaux Zotero ont été réalisés avec l’assistance de ChatGPT. Les documents Word et le classeur fournis ont été copiés sans modification de leur contenu.
